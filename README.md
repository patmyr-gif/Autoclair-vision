# AutoClair V52

Version complète à mettre dans le dépôt GitHub.

Architecture:
PHOTO/PDF COMPLET
→ Vision GPT-5.6
→ compréhension du document entier
→ JSON structuré
→ relecture ciblée du VIN
→ relecture ciblée de la motorisation si nécessaire

## Render

Build command:
npm install

Start command:
npm start

Environment:
OPENAI_API_KEY = clé API OpenAI

Optionnel:
OPENAI_MODEL = gpt-5.6-sol

## Important

Le fichier d'entrée de l'interface est `public/index.html`.
Le moteur est `server.js`.
